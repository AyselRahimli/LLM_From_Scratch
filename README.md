This repository is my hands-on implementation of Sebastian Raschka’s Build a Large Language Model (From Scratch), in which I build a GPT-style language model step by step using PyTorch. It starts with text processing: tokenization, byte-pair encoding with tiktoken, sliding-window data sampling, and token and positional embeddings. It then implements attention, progressing from simple self-attention to causal and multi-head attention. These pieces are assembled into a full GPT-2 architecture with layer normalization, GELU feed-forward layers, shortcut connections and transformer blocks. The model is pretrained on a short story (The Verdict) and can also load OpenAI’s pretrained GPT-2 weights. I then fine-tune it in two ways: as an SMS spam classifier, and as an instruction-following assistant whose answers are scored with Llama 3 through Ollama. The repository also covers training improvements (learning-rate warmup, cosine decay and gradient clipping) and parameter-efficient fine-tuning with LoRA. The goal of the project is to understand how modern LLMs work internally by writing every core component myself instead of relying on high-level libraries.
